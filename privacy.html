Privacy Policy

Last updated: October 1, 2026

1. Summary

AutoPost Bot ("the App") runs locally on the owner's computer. It has no servers, no user accounts of its own, and does not sell or share personal data.

2. Data we access from TikTok

  • user.info.basic — your TikTok open ID and basic profile info, used only to identify the connected account.
  • video.publish / video.upload — used only to upload videos created by the App to your own TikTok account.
  • Creator information (privacy options, maximum video length) — used only to choose valid posting settings.

3. How data is stored

OAuth access and refresh tokens are stored only in a local file on the owner's computer. They are never transmitted anywhere except to TikTok's official API (open.tiktokapis.com) when publishing videos.

4. Third-party services

To create videos the App sends non-personal data to: a text-generation API (story text), Microsoft text-to-speech (story text), and Pixabay/Pexels (search keywords for background footage). No TikTok data is sent to these services.

5. Data retention and deletion

You can delete all stored data at any time by deleting the App's local token file, and revoke the App's access in TikTok: Settings and privacy → Security → Manage app permissions.

6. Children

The App is not intended for use by anyone under 18.
